# Rice Motorsport site export

This folder was created by splitting your pasted code into separate website files.

## Files
- `index.html` — Home page
- `about.html` — About page
- `car.html` — The Car page
- `season.html` — Season page
- `sponsorship.html` — Sponsorship page
- `assets/css/styles.css` — shared custom CSS helpers
- `assets/js/main.js` — shared JS starter file

## Notes
- The original per-page Tailwind config is still inside each page so the design stays close to what you pasted.
- Shared CSS/JS files were added so you have a cleaner starting point in VS Code.
- Nav/footer links were updated to point to the new page files where possible.
- Some CTA buttons were given simple page redirects.
- Forms and interactive features are still mostly visual and will need real functionality later.

## Recommended next steps
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Replace placeholder text, sponsor names, and any demo content.
5. Add a real form handler if you want email/contact submissions.
